# 🧪 Laboratorio 2.6 — Información de una cuenta bancaria

* **Estudiante:** Jeico Arias Brito
* **Curso:** Fundamentos de Programación con C#

---

## 📋 Descripción de la tarea

Crear una aplicación de consola en C# que solicite interactiva y dinámicamente al usuario los datos básicos de una cuenta bancaria (cliente, número de cuenta, tipo y saldo) y muestre en pantalla un resumen formateado de dicha información.

### Datos solicitados al usuario:
* Nombre del cliente
* Número de cuenta
* Tipo de cuenta
* Saldo actual

---

## 🎯 Objetivos técnicos aplicados

* Declaración y manejo correcto de **variables y tipos de datos** (`string`, `decimal`/`double`).
* Lectura de entradas de consola mediante **`Console.ReadLine()`**.
* Salida y formato en pantalla usando **`Console.WriteLine()`**.
* Uso de **interpolación de cadenas** (`$""`) para formatear los valores ingresados.
